# Этап 1: графический REPL

Документ описывает коммит `5f4ece3`, где `ls` и `cd` — заглушки. Для отдельной
копии используйте `git worktree add ../shell-stage-1 5f4ece3`. В текущей версии
демонстрируйте работающие файловые команды по [этапу 4](stage-4.md).

Подготовьте зависимости и интерфейс:

```sh
make setup
make build
./run.sh
```

Откройте напечатанный локальный адрес, если браузер не открылся автоматически.
Выполняйте строки ниже по одной. Команду `exit` оставьте на конец демонстрации.

## 1. Реальные данные ОС

Сравните заголовок страницы `Эмулятор - [username@hostname]` с выводом
настоящего терминала:

```sh
id -un
hostname
```

Заголовок берёт данные процесса, в котором запущен сервер.

## 2. Заглушки и аргументы

```text
ls
ls first second
cd /example
```

Вывод содержит имя вызванной команды и её аргументы. Заглушка `cd` не изменяет
текущий каталог настоящей ОС. Загрузка VFS добавлена на этапе 3.

## 3. Переменные и кавычки

```text
ls $HOME
ls ${HOME}
ls "$HOME"
ls '$HOME'
ls "имя с пробелами" "" escaped\ argument
ls # комментарий вне кавычек
ls "# это аргумент"
```

Первые три команды показывают значение `HOME` окружения сервера. Одинарные
кавычки сохраняют строку `$HOME`. Кавычки объединяют слова в один аргумент;
пустые кавычки сохраняют пустой аргумент. Символ `#` внутри кавычек не начинает
комментарий. Отправьте также пустую строку и убедитесь, что ошибка не появляется.

## 4. Ошибки и продолжение сеанса

```text
unknown
cd first second
exit unexpected
ls "незакрытая строка
ls ${HOME
ls after-error
```

Проверьте диагностику неизвестной команды, лишних аргументов, незакрытой
кавычки и некорректной подстановки. Последняя строка должна исполниться:
ошибка отдельной команды не завершает приложение.

## 5. Интерфейс и восстановление

1. Нажмите вверх/вниз и проверьте перемещение по истории.
2. Начните новую строку, перейдите вверх и вернитесь вниз: черновик сохраняется.
3. Выделите и скопируйте часть вывода.
4. Обновите страницу: предыдущий диалог остаётся видимым.
5. Выполните ещё одну команду и убедитесь, что она появилась ровно один раз.

## 6. Завершение

```text
exit
```

Сеанс завершается, ввод отключается, диалог остаётся во вкладке. Настоящий
терминал возвращается к приглашению после завершения локального процесса.
Чтобы повторить демонстрацию, запустите приложение заново.

## Автоматические проверки

```sh
make test
make check
```

При защите покажите результаты проверок и коммит этапа с его подробным
описанием: `git log -1 --format=fuller`.
