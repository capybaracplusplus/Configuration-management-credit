# Этап 4: основные команды

Заглушки `ls` и `cd` заменены операциями над VFS. Добавлены `echo`, `uniq`
и `cal`. Ни одна команда не выполняет программы настоящей ОС.

## Запуск демонстрации

```sh
make setup
make build
./scripts/commands.sh
```

Сценарий ОС генерирует наборы данных и запускает эквивалент команды:

```sh
./run.sh --vfs .generated/vfs/deep.zip --startup-script demos/stage-4.emu
```

Демонстрация содержит намеренные ошибки. Они должны появиться с именем
сценария и номером строки, после чего выполнение продолжается. Последняя
строка сообщает о завершении проверок. Сеанс остаётся открытым для ручного
ввода; после просмотра выполните `exit`.

## Что проверить в диалоге

| Команда | Примеры и ожидаемые свойства |
| --- | --- |
| `ls` | Имена отсортированы; `-a` показывает `.hidden`, `.` и `..`; `-l` показывает права и размер; `-al` объединяет режимы. |
| `ls ПУТЬ ...` | Допустимы файлы и каталоги; пробелы и Unicode в имени сохраняются; доступные пути выводятся даже при ошибке другого пути. |
| `cd` | Приглашение меняет каталог; относительные пути, `.`, `..`, `-` и виртуальный `$HOME` работают; выход выше `/` невозможен. |
| `echo` | Аргументы разделены пробелами; пустой вызов печатает перевод строки; `-n` убирает только конечный перевод строки. |
| `uniq` | Обрабатываются соседние группы строк; поддержаны `-c`, `-d`, `-u`, сочетания с `-c` и конец параметров `--`. |
| `cal` | Текущий месяц, весь год, отдельный месяц; воскресенье в первом столбце; февраль 2024 содержит 29 дней. |

В начале демонстрации `cd -` должен сообщить, что предыдущий каталог ещё
не задан. После успешных переходов эта форма возвращает предыдущий каталог
и печатает его путь. `cd` без аргументов использует настоящий `$HOME` как имя
виртуального каталога; генератор создал его без чтения настоящих файлов.

Файл `/assets/payload.bin` содержит семь байтов. Его размер виден через
`ls -l`; попытка `uniq` должна сообщить об ошибке UTF-8.

### Почему `uniq` оставляет последнюю `alpha`

Исходный файл `/docs/repeated.txt` содержит:

```text
alpha
alpha
beta
beta
gamma
alpha
```

Обычный `uniq` выдаёт `alpha`, `beta`, `gamma`, `alpha`. Последняя `alpha`
не соседствует с первой группой, поэтому остаётся. В режиме `-d` остаются
`alpha` и `beta`, в режиме `-u` — `gamma` и последняя `alpha`.
`-c` показывает длины групп: 2, 2, 1, 1; его можно сочетать с отбором групп.

### Ошибки аргументов и данных

Проверьте неизвестные параметры, отсутствующие пути, попытку `cd` в файл,
лишние аргументы, отсутствие файла у `uniq`, чтение каталога, бинарные данные,
несовместимые `-d`/`-u`, неверные годы/месяцы и неизвестную команду.
Незакрытая кавычка и подстановка должны по-прежнему выдавать ошибки парсера.

Календарь принимает годы 1–9999, месяцы 1–12. Английские заголовки выбраны
для воспроизводимости, а текущий месяц определяется по локальной дате ОС.

## Ручная проверка после сценария

```text
cd /docs
ls -l
uniq -c repeated.txt
echo "$HOME"
cal 2 2024
```

Обновите страницу: рабочий каталог `/docs` и весь диалог должны сохраниться.
Вернитесь в корень командой `cd /` и завершите работу командой `exit`.

## Автоматические проверки

```sh
make test
make check
make build
make fixtures
npx playwright install chromium firefox
npm run test:e2e
```

Установка браузеров нужна только перед первым браузерным запуском.
Тесты проверяют режимы команд, пути, права, границы календаря, соседние
и разделённые дубликаты, а также совместную работу GUI и Python-сервера.

Демонстрации этапов 1–3 сохранены для их исторических коммитов. В текущей
версии `ls`/`cd` уже работают с VFS и не печатают представление аргументов.
